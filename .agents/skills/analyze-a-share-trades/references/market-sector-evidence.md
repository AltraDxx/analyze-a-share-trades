# 市场与板块证据

仅在市场级、板块级或产业链反馈能够检验当前事件判断、改变风险预算或帮助全市场发现候选时读取。以下内容是证据菜单，不是八维打分表、固定自上而下流程、事件标签库或多选题。

## 市场级事件

“大盘操盘手”是公开行为中占据边际定价权的主导合力简称，不代表统一指挥或已识别真实账户。市场级事件判断优先回答：

- 行为模式从何时发生变化，整个事件最终试图实现什么盘面结果；
- 已完成哪些步骤，当前处于什么阶段，眼下必须完成什么；
- 当前动作应留下怎样的指数、宽度、成交、风格和核心权重痕迹；
- 市场是否跟随、承接或拒绝，该反馈如何影响板块、个股和用户动作。

只有参与者、仓位、流动性或对手盘能够解释关键行为、能力边界或不同反馈时才展开，不为形式完整逐项填写。

按区分力选择证据：

- 指数高低点、不同宽基的分化与权重贡献；
- 上涨/下跌家数、收益中位数、新高新低、涨跌停与炸板；
- 成交相对常态、成交集中度、价格推进效率；
- 强势股次日反馈、核心/中军/跟随梯队和亏钱效应；
- ETF 申赎、融资、互联互通等较接近持仓变化的数据，以及资金流代理与价格响应；
- 政策、宏观流动性、汇率、外围和尾部事件的实际传导链。

均线、资金流、单日成交或外围涨跌不能单独定义市场意图。指数与宽度、资金代理与价格、消息与反馈冲突时，优先检查口径和哪个事件解释预测了这种冲突。

## 同日市场快照

首次确需市场判断时形成精简 `market_game_snapshot`：

```text
trading_date / snapshot_as_of / session / freshness
event_start_or_change / event_goal
concise_inference_chain / relevant_competing_explanation
stage / current_action / observed_feedback
next_required_footprint / validation_deadline
invalidation_or_transition / downstream_effect
```

同一北京时间交易日后续股票先复用并做轻量新鲜度检查。只有交易阶段跨越、重大事件、预期痕迹未按时出现、失效条件触发或风险状态显著变化时才增量更新；不得跨交易日沿用。

## 板块与主线事件

主线不是涨幅榜第一或概念标签。板块事件的目标必须从连续行为中开放推断，不从“启动、扩散、回流、退潮”等预设选项中挑选；5/10/20 日窗口只是按需观察注意力和反馈的证据，不是事件边界。

能检验板块事件判断的证据通常包括：

- 叙事是否有可验证的需求、供给、付款方和利润传导；
- 等权/中位数相对收益是否从 5 日延伸至 10/20 日；
- 成交份额是否持续、是否从核心扩散至产业环节；
- 上涨宽度、创新高数量以及核心、中军、弹性和跟随是否形成反馈；
- 催化是否由订单、价格、产能、政策或业绩继续验证；
- 龙头调整时是否有承接，回流时谁率先恢复价格推进。

若判断涉及资金迁移，只有旧筹码承接、新增需求或容量差异会改变事件解释时才展开，并写出迁移应如何改变成交份额、宽度和核心价格。若只有一个高标或一日新闻脉冲，不能命名持续主线；允许无明确主线或多线轮动。

## 产业和公司角色

只在产业角色能区分事件解释或生成候选时建立：

```text
叙事 → 产业簇 → 细分环节 → 供需瓶颈/利润池 → 公司可验证暴露
```

公司角色需分别用事实确认：

- **产业核心**：收入/利润暴露、市场份额、产能、客户、壁垒和利润传导；
- **盘面核心**：板块启动或回流时领先、成交容量、抗跌和带动性；
- **情绪核心**：短线辨识度和风险偏好影响；
- **趋势中军/阶段性新核心/弹性/跟随**：以当前成交、反馈和带动关系判断。

角色是随 `analysis_as_of` 变化的证据，不是买入结论。互动平台、概念成员或大模型联想不能单独证明业务暴露；不可推荐的创业板或科创板核心只能作观察锚。

## 更新与停止

使用 [scan_mainlines.py](../scripts/scan_mainlines.py) 计算的 5/10/20 日强度只是候选证据，不直接命名主线或决定股票。市场或板块资料只有能够改变候选来源、事件判断、风险预算或交易动作时才继续扩展。

若市场/板块不同解释导向同一动作，说明具体意图无需判断；若它们导向不同动作且关键反馈无法区分，说明动作相关分歧、下一判别点和时间窗口，按主 skill 风险规则处理。
