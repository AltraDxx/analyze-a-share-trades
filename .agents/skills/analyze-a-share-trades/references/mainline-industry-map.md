# 滚动主线与产业图谱

本文件用于识别“近期资金和注意力集中在哪里”，并把宽泛题材拆到可验证的产业环节和公司角色。它回答：

1. 当前是否存在主线、次主线或仅有快速轮动？
2. 资金从哪个叙事流向哪些产业簇和细分环节？
3. 某只沪深主板普通 A 股是产业核心、盘面核心、中军、弹性、补涨，还是弱映射？
4. 板块资金更可能在启动、扩散、轮动、回流、护持、兑现还是撤退，它是在顺应大盘、借大盘完成另一目的，还是暂时脱钩？

主线不是单日涨幅榜第一，也不是数据商概念标签。允许双主线、多线轮动和“当前无明确主线”。

## 一、范围与基本定义

- **候选股票池**：仅沪深主板普通 A 股，排除 ST、创业板、科创板和流动性明显不足的股票。
- **信号观察池**：可观察全 A、港股及海外公司和指数。不可交易的龙头可作为产业景气或情绪锚，但不得进入推荐结论。
- **主题/叙事**：资金共同交易的因果命题，如“AI 算力投资扩张”。
- **产业簇**：同一叙事下具有不同商业模式的行业集合，如半导体、服务器、数据中心电力。
- **细分环节**：产业链中的具体产品或服务，如 MLCC、覆铜板、液冷。
- **瓶颈**：短期供给难扩、认证周期长、技术壁垒高或产能受限，因而可能获得定价权的环节。
- **主线**：叙事、价格、成交、板块宽度、核心股票结构和基本面验证在多个观察窗口形成持续共振的方向。

不得把“概念板块成员”直接等同于主营受益，也不得因为某只股票涨停就倒推整条产业链已经成为主线。

## 二、使用滚动 5/10/20 日窗口

以分析时点能获得的最后完整交易数据为终点，三个窗口承担不同职责：

| 窗口 | 主要问题 | 不应过度解释 |
|---|---|---|
| 5 日 | 是否刚启动、加速、回流或出现突发催化？ | 可能只是事件脉冲或一日情绪 |
| 10 日 | 资金和板块宽度是否持续，是否形成梯队？ | 不能单独证明产业兑现 |
| 20 日 | 是否达到“月度级主线”强度，内部是否完成扩散？ | 可能已成熟甚至拥挤，不代表仍适合追高 |

可用更长窗口说明背景，但不得替代 5/10/20 日的近期判断。自然月只用于复盘命名，不把月初和月末人为切断同一行情。

盘中只能用截至当时的部分数据作临时判断；成交额份额应与历史同一时刻比较。盘前使用上一交易日完整窗口，集合竞价只作为当日验证，不改写历史窗口。

有板块、行业或产业长表 CSV 时，优先运行 [scan_mainlines.py](../scripts/scan_mainlines.py) 确定性计算 5/10/20 交易日收益、可选基准相对收益、量能比、上涨家数宽度和近 5 日正收益持续性。脚本排名只用于生成待核验的强度证据，不直接命名主线或给出买卖结论。概念、主题和行业成分可能重叠，禁止把多个实体的成交额相加后称为全市场成交份额；全市场份额必须来自互斥分类或经过成分去重的底层证券数据。

## 三、主线识别的证据链

不要做固定权重总分。按下列顺序逐层验证，一层明显不成立时保留为“候选叙事”而不是主线。

### 1. 叙事是否可重复验证

明确写出：

- 需求或供给变化是什么。
- 谁支付、谁受益、利润如何传导。
- 催化是一次性消息，还是存在订单、价格、产能、政策和业绩的后续验证。
- 哪些事实会证伪叙事。

无法写出因果链的热词，只能归为情绪题材。

### 2. 是否获得相对收益

同时观察：

- 板块等权或个股中位数相对宽基的超额表现。
- 5/10/20 日方向是否从短向长扩散，还是只有 5 日脉冲。
- 上涨是否覆盖多数成员，还是由一两只大市值股票贡献。
- 回调后是否仍保持相对强度。

优先使用中位数、等权和宽度，避免市值加权指数掩盖内部走弱。

### 3. 成交注意力是否持续

观察：

- 板块成交额占全市场成交额的份额及变化。
- 放量后能否维持合理活跃度，而非次日迅速消失。
- 成交是否从核心扩散至产业链相关环节。
- 板块资金流代理在多个日段是否与价格结果一致。

成交额份额代表注意力，不等于净流入；数据商“主力净流入”只作辅助证据。

### 4. 板块宽度与梯队是否完整

检查：

- 上涨家数、站上 5/10/20 日均线比例、创新高数量。
- 龙头、趋势中军、弹性标的和低位补涨是否形成分工。
- 核心调整时是否有其他环节承接，还是全板块同步瓦解。
- 不可交易的创业板或科创板核心走强时，主板是否存在真实映射且获得资金确认。

只有高标而没有中军和扩散，通常是局部情绪；只有低位普涨而没有核心，可能是短期轮动。

### 5. 催化与基本面是否接力

区分：

- 政策或新闻首次提出。
- 公司订单、产品价格、开工率、产能和客户验证。
- 业绩预告、盈利预测或现金流能否体现。
- 市场预期是否已经充分反映在股价和估值中。

利好发布后价格不再响应，是“已定价或低于预期”的证据，不应继续累积为利好分。

### 6. 外围是否形成产业映射

美国是默认重点；韩国、日本、港股、台股市场、欧洲和商品按产业加载。例如：

- 半导体/AI：美国科技与半导体、韩国存储、台股供应链、日本设备。
- 电池：韩国电池链、相关商品价格及海外政策。
- 机器人/汽车：日本、德国和美国相关产业。
- 有色：美元、实际利率和对应商品价格。

外围只能确认产业景气或风险偏好，不能替代 A 股自身价格、宽度和成交验证。

## 四、主线阶段

阶段判断决定可用策略和预期持有窗口，不表示未来必然按顺序发展。

| 阶段 | 识别特征 | 容易误判之处 | 交易含义 |
|---|---|---|---|
| 萌芽 | 5 日相对强，催化清晰，成交开始聚集，但 10/20 日尚未确认 | 单日新闻脉冲 | 只列候选或试探，等待板块宽度和次日承接 |
| 确认 | 5/10 日相对强度和成交份额持续，核心与中军出现，20 日开始改善 | 追逐最强一日 | 适合突破、首次分歧或回调确认 |
| 扩散 | 资金从核心环节扩展到上下游，梯队完整，主板出现可交易映射 | 把所有沾边公司都算受益 | 比较环节利润弹性与公司业务纯度，淘汰伪概念 |
| 加速/拥挤 | 核心快速上涨、成交集中、叙事高度一致，补涨大量出现 | 把一致预期当低风险 | 不因主线正确忽略当前价格风险，重点监控放量滞涨与分时派发 |
| 分化 | 核心尚强但宽度、溢价或成交份额转弱，弱映射先掉队 | 看到龙头未跌就认为板块健康 | 汰弱留强、降低追高，检查主线能否回流 |
| 回流/二波 | 调整后核心率先修复，板块成交份额和宽度重新改善，并有新催化或业绩验证 | 普通反抽被命名为二波 | 只有价格、成交、宽度共同恢复才升级 |
| 退潮 | 核心结构破坏，板块相对收益和成交份额下降，亏钱效应扩散 | 用旧叙事解释所有下跌为洗盘 | 停止补涨搜索；反弹优先作为退出或等待再确认 |

阶段可以在不同细分环节间错位。例如 AI 总叙事仍处于扩散，光模块可能已拥挤，电力设备可能刚进入确认。

### 板块层意图与大盘耦合

主线阶段是板块意图的证据，不等于意图本身。分析具体股票时，板块层不单独展开一对假设，而是分别成为两条完整三层路径中的板块环节。至少说明：

- 板块资金当前要解决的问题及约束；
- 核心、中军、补涨和跟随之间谁在引导、谁在被动响应；
- 与大盘层属于顺势共振、借势操作、被动拖累、逆势控盘还是暂时脱钩/反向引领；
- 下一步应出现的成交份额、宽度、核心反馈和资金迁移；
- 哪个事实会使板块意图解释失效。

同一方向上涨不等于同一意图。例如大盘反弹时板块放量上涨，既可能是新主线确认，也可能是前主线借市场回暖制造流动性后兑现；必须用核心价格推进效率、板块宽度和后续承接区分。

## 五、允许“无明确主线”

出现以下情况时输出“无明确主线”或“快速轮动”，不要硬选涨幅最高板块：

- 5 日强势方向在 10/20 日没有持续性。
- 板块成交份额快速切换，没有稳定核心。
- 指数靠权重维持，但行业中位数和宽度普遍弱。
- 多个主题只有单次消息刺激，次日承接差。
- 资金代理、价格和板块宽度相互矛盾。
- 数据不足以区分主线与短期脉冲。

无主线本身是决策结果，通常意味着降低出手频率、缩短持有窗口或等待确认。

若存在两个持续方向，分别标注“主线 A / 主线 B”，说明它们是共振、轮动还是资金跷跷板，不强行合并。

## 六、建立产业图谱

对每个主线使用以下层级：

```text
核心叙事
└─ 产业簇
   └─ 细分环节
      └─ 供需瓶颈/利润池
         └─ 公司角色与可验证暴露
```

每个节点至少记录：

- 节点名称和上下游关系。
- 收入来源、成本承担者和利润传导逻辑。
- 当前催化及发生日期。
- 关键验证指标及最新数据日期。
- 对应 A 股公司及业务暴露证据。
- 替代环节、竞争关系和主要证伪条件。

一家公司可以属于多个节点，但每条映射都要单独记录业务占比、产品进度和证据来源。概念标签、互动平台表述或大模型联想不能单独证明业务暴露。

### 资金迁移路径

除板块排名外，跟踪同一叙事内部的迁移：

- 上游瓶颈 → 中游设备/材料 → 下游应用。
- 高辨识度核心 → 趋势中军 → 低位补涨。
- 硬件主链 → 配套电力/散热/元件。
- 国内催化 → 海外映射，或海外业绩 → 国内供应链。

记录迁移发生时的成交份额、相对强弱和催化，区分健康扩散与高位资金寻找低位出口。

## 七、AI 基建示例

“AI 基建”不是一个单一板块，可拆为：

```text
AI 训练与推理需求增长
├─ 算力与半导体
│  ├─ 加速芯片、CPU、ASIC
│  ├─ 存储与高带宽存储相关环节
│  ├─ 半导体设备、材料、先进封装
│  └─ 功率半导体
├─ 服务器与高速互联
│  ├─ 服务器整机、ODM、机柜
│  ├─ 交换机、光模块、光器件
│  ├─ 高速铜连接、连接器
│  └─ PCB、覆铜板
├─ 电子元件
│  ├─ MLCC 等被动元件
│  ├─ 电感、电容、磁性器件
│  └─ 高可靠电源与电源管理
├─ 数据中心基础设施
│  ├─ UPS、供配电、变压器
│  ├─ 液冷、温控
│  ├─ IDC、云与算力租赁
│  └─ 电网、储能和能源配套
└─ 软件与运营
   ├─ 云平台、调度
   └─ 数据、模型和行业应用
```

分析时不要因为“AI 需求增长”就默认所有节点同步受益。逐环节回答：

- AI 服务器或数据中心对该产品的单位用量是否提高？
- 需求增量能否转化为订单、价格或产能利用率？
- 该环节是否供给受限，还是容易快速扩产导致利润被稀释？
- 公司相关产品是否已量产、认证或只是研发规划？
- 相关业务占公司收入和利润的比例是否足以影响业绩？
- 海外产业信号是否与国内公司真实客户链对应？

例如，韩股存储龙头走强可作为存储周期和风险偏好的观察锚；它不能自动证明某家 A 股 MLCC、设备或材料公司的订单增长。仍需公司公告、财报、客户认证、产品价格和 A 股盘面确认。

## 八、龙头、公司角色与稀缺性

“是否是龙头”不是一个布尔字段，也不等于当前应该买入。分别判断产业地位、盘面带动、情绪辨识度、趋势容量和阶段变化。

### 1. 产业龙头/产业核心

需要多类业务证据支持：

- 相关业务收入、利润和订单暴露较高。
- 市占率、产能、客户质量或行业排名有可靠来源。
- 产品位于瓶颈或高利润环节。
- 客户认证、技术、专利、工艺或规模形成进入壁垒。
- 景气上行能够传导至收入、毛利率或现金流。

“公司称已布局”“产品可用于”不足以认定产业龙头。产业龙头还要比较同环节竞争者、市场份额、利润池地位和客户认可，不能只看公司绝对规模。

### 2. 盘面龙头/盘面核心

用市场行为确认：

- 在板块启动、回流时率先走强。
- 成交额占板块较高且具有持续性。
- 板块调整时相对抗跌，修复时率先收复。
- 对同链股票具有明显带动作用。
- 日线趋势、分时承接和板块联动相互验证。

盘面龙头必须具有带动性，而不只是自身涨幅大。检查它是率先带动板块，还是被其他核心被动带起；地位是在强化、维持还是被新核心替代。

盘面龙头可能不是产业龙头；两者重合时逻辑更完整，但仍要检查一致预期、拥挤和当前价格所承担的风险。

### 3. 情绪龙头

情绪龙头由短线辨识度、连板/强势高度、成交注意力和市场情绪影响确认。它可以主导风险偏好，却未必有最强产业暴露，也未必适合追入。重点检查：

- 它能否继续带动同梯队和板块；
- 强势是持续换手还是只剩单一高标；
- 一致加速后是否出现亏钱效应和承接下降；
- 情绪龙头倒下时产业龙头或趋势核心能否独立维持。

### 4. 趋势核心/容量中军、阶段性新核心、弹性与补涨

- **趋势核心/容量中军**：容量较大、成交稳定、能代表板块趋势，不要求涨幅最大。
- **阶段性新核心**：资金迁移、增量事件或产业验证后新近获得带动性；必须确认其地位不是一日脉冲。
- **弹性标的**：市值或筹码结构使其涨跌更快，但风险和拥挤通常更高。
- **补涨**：主线扩散后才被发现，需证明产业映射，且持有窗口通常短于核心。
- **跟随股**：主要在龙头走强后被动响应，缺乏独立产业或资金证据。
- **弱映射/伪概念**：业务暴露无法验证、占比过低，或只依赖名称和互动平台联想。

同一公司可以同时是产业龙头、盘面龙头或趋势核心，也可能只满足其中一种。对每个角色记录证据和 `analysis_as_of`；不得沿用过期龙头标签。

### 5. 稀缺性证据

稀缺性是可验证的供给约束，不是形容词。检查：

- 可替代供应商和可比上市公司的数量及能力。
- 市场份额、有效产能和扩产周期。
- 客户认证周期、切换成本和合格供应商资格。
- 技术、专利、工艺良率、资源或牌照壁垒。
- 供需紧张时是否具备提价能力。
- 替代技术、客户自研和竞争者扩产的威胁。

证据优先级：

1. 公司公告、定期报告、交易所问询回复和监管文件。
2. 客户或供应链对手方披露、行业协会和正式统计。
3. 多家有方法说明的研究机构交叉验证。
4. 新闻、产业访谈和互动平台，只作线索。
5. 大模型推断不得作为事实证据。

对每项稀缺性注明证据日期；过时的市占率或认证信息不能直接用于当前结论。

## 九、从主线到主板候选

### 1. 先形成关注方向

按“大盘层意图快照 → 市场状态与三层耦合 → 板块资金意图 → 主线/次主线/轮动/退潮 → 产业环节与资金迁移 → 龙头梯队”确定少量关注方向。公司级独立事件也可以成为一个关注方向，但必须有原文、真实公司暴露和市场价格反馈。

### 2. 与硬过滤股票池取交集

先通过沪深主板、非 ST、非停牌和流动性硬过滤，再合并已经核验的“关注方向—公司”关系。优先使用 [build_candidate_pool.py](../scripts/build_candidate_pool.py)：

- `--universe` 使用 [filter_universe.py](../scripts/filter_universe.py) 的 JSON；
- 关系 CSV 至少含 `code`、`focus`、`mapping_status`，可补 `source_kind`、产业簇、细分环节、产业角色、盘面角色、龙头类型和证据引用；
- `focus` 可以是已选主线、新方向、公司独立事件或其他已核验的分析方向；事件进入同一候选池，不形成独立结论模式；
- 聚合同一公司在多个方向、产业环节和龙头角色中的记录；
- 只生成待深度分析池，不判断值得买；
- 不打分、不排名，也不把证据完整度作为股票先后次序；
- 只按代码稳定输出，稳定顺序不代表质量；
- 候选超过容量上限时直接要求上游继续收窄，不截断 Top N。

### 3. 对候选逐只形成完整交易逻辑

综合分析而不是按固定优先级依次打勾：

- 产业暴露和利润传导；
- 主线与细分阶段；
- 产业龙头、盘面龙头、情绪龙头、趋势核心/中军、阶段性新核心或跟随角色；
- 公司事件、基本面和相对预期；
- 日线、成交、分时、主导资金行为和人性博弈；
- 当前市场是否允许该股票适用的策略；
- 当前价格位置和需要承担的风险。

数据完整度只决定能否正式判断和结论强度。最终允许多只股票分别值得买，也允许一只都没有；除非用户明确要求，不强制排名或选首选。每只通过深析的股票分别锁定一个主策略。

不可交易的创业板、科创板龙头只能作为观察锚。主板映射若明显更弱，应输出“主线存在，但当前主板无合格候选”，不能为了给出股票而降低标准。

## 十、证据冲突与置信度

常见冲突：

- **产业证据强、盘面弱**：可能尚未定价，也可能市场不认可；等待价格和成交确认。
- **盘面强、产业证据弱**：按情绪或事件交易处理，缩短预期窗口，不包装成产业核心。
- **5 日强、10/20 日弱**：标记萌芽或脉冲，不叫月度主线。
- **20 日强、5 日转弱**：可能处于分化或退潮，历史涨幅不代表当前吸引力。
- **板块强、主板映射弱**：允许不推荐。
- **资金代理流入、板块宽度下降**：降低置信度，观察核心承接和次日扩散。

不输出伪精确概率或综合分。使用：

- **高置信度主线**：多窗口持续，价格、宽度、成交、梯队和产业验证大体一致。
- **中置信度主线/候选主线**：方向清楚但窗口较短、验证不足或存在一项重要冲突。
- **低置信度主题**：主要由消息、单股或代理资金推动，尚无持续结构。

## 十一、DeepSeek/大模型的使用边界

可用于：

- 新闻去重、归类和时间线提取。
- 从公告中提取产品、订单、客户、产能和风险线索。
- 把叙事映射为候选产业图谱。
- 生成竞争性解释和待验证问题。

不得用于：

- 凭记忆确认收入占比、市场份额、客户关系和稀缺性。
- 生成缺失的行情、成交或资金数字。
- 用语义相似度直接认定公司属于主线。

所有大模型提取结果都回链到原文；无法回链则标记“待核实”。

## 十二、缺失数据与标准输出

若缺少板块行情、成交份额或个股联动，可请用户提供带日期和时间的：

- 行业/概念涨幅、成交额和资金排名截图。
- 5/10/20 日板块走势或 K 线。
- 板块核心股和候选股分时截图。
- 公司公告、财报或业务构成页面。

截图只能补足可见事实，无法证明未展示的历史持续性和业务关系。

主线输出至少包含：

```markdown

- 两条完整三层路径中的板块解释：
- 下一确认与失效条件：
- 主线名称与置信度：
- 5 日证据：
- 10 日证据：
- 20 日证据：
- 当前阶段：
- 核心叙事与证伪条件：
- 产业簇 → 细分环节 → 瓶颈：
- 资金迁移路径：
- 产业龙头 / 盘面龙头 / 情绪龙头 / 趋势核心或中军 / 阶段性新核心 / 跟随：
- 沪深主板待深析候选及其来源：
```

结论必须能够写成一句可验证的话，例如：

不得只输出“AI、新能源、消费值得关注”这类无法指导选择和复核的宽泛列表。
