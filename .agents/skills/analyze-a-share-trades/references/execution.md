# 策略、风险与执行

仅在盘面事件判断已经更新，但具体交易剧本、组合风险、仓位、T+1、涨跌停或特殊执行仍会改变动作时读取。

## 从事件到策略

先根据最受支持的事件目标、所处阶段、当前动作、实际反馈和可观察触发条件，为每只股票锁定一个主策略：

- 新事件尚未充分定价：事件驱动；
- 持续新增需求、核心地位和承接仍在：强势延续；
- 板块资金从核心扩散且平台有效突破：突破与扩散；
- 原主线整理后重新获得成交、宽度和核心反馈：回流；
- 中期趋势未破、卖压缩减并在支撑重新承接：趋势回调；
- 非基本面冲击后卖压衰减并修复：恐慌修复；
- 事件判断不清、价格风险不合算或环境不支持：空仓/不交易。

策略名只是执行简称，不替代事件推断。不得把多个策略的宽松条件拼成一笔交易；入场后不得因下跌把突破或事件交易改成长线持有。每笔策略写清触发、确认、失效、退出和基础持有窗口，硬失效优先于预计期限。

## D1 与复核

- 提问日是交易日时当日为 D1；非交易日时其后的首个交易日为 D1。
- D1 收盘后只能下一交易日执行时写“最早可执行：D2”，不重编号。
- 持有和复核只用 D1—Dn，不输出未来自然日期。
- 已有持仓从本次 D1 判断未来，不计算、询问或输出已持有天数。

## 股票池与仓位

买入只限沪深主板普通 A 股，并满足主 skill 的流动性门槛。已有持仓即使不合格仍分析退出。

30% 是组合净值灾难回撤硬上限，不是单股止损或满仓依据；风险应在接近上限前降低。无法取得完整净值时只做已知持仓和单票判断。

仓位由用户风险预算、退出距离、跳空/滑点、T+1、波动、事件和相关暴露共同决定。用户未给预算时只用“试探仓、分批、确认后增加”等定性表达，不自创精确比例。不得因浮亏摊低、因模型信心取消退出或建议杠杆。

多只股票依赖同一主题、客户、商品、政策或海外变量时视为相关风险。用户未提供完整持仓时说明未完成组合相关性检查。

## A股执行

- 普通 A 股当日买入后不能当日卖出；D1 新买仓位若逻辑转弱，只能给 D2 优先处理并披露隔夜风险。
- 停牌、账户无可卖证券或资金等已确认事实是硬限制；实际可卖数量以账户为准。
- 没有实时盘口时给区域、条件或关键位，不保证成交价格。
- 特殊交易时段按 [data-access.md](data-access.md) 核验现行规则和参与者，不能根据时段猜账户身份。

### 涨跌停

按统一顺序：

```text
先假设能够成交，判断 D1 应不应该交易
├─ 应交易：给尝试方案，不承诺成交
│  ├─ 实际成交：进入成交后的持有/退出策略
│  └─ 未成交或部分成交：按真实仓位给 D2 条件预案
└─ 不应交易或已无适用时段：直接给 D2 条件预案
```

不把一字板直接写成必然买不到或卖不掉，不建立可交易性三态，不把提交委托写成已经成交。T+1、停牌等确定性限制仍直接执行。

## 持仓与卖出

持仓诊断按严重性检查能否证伪原事件或交易逻辑：

1. 财务真实性、监管、退市或持续经营风险；
2. 原始交易逻辑或事件被证伪；
3. 主线、核心地位或公司角色实质恶化；
4. 日线、成交、承接或相对反馈符合撤退/派发等竞争解释；
5. 达到策略目标、失效条件或机会成本窗口。

成本、仓位和原始理由只用于账户动作，不能把已经失效的事件解释回来。若继续持有，写下一确认和提前退出条件；若退出，按真实可执行性给 D1/D2 方案。

## 动作相关分歧尚未区分

合理事件解释导向同一动作时写“具体意图无需判断”。若未证伪解释会导向不同的开仓、持有、仓位或退出动作且暂时无法区分：

- 未持仓默认等待；只有当前必要动作已经开始、失败边界清晰、预期反馈有明确时间窗口且 T+1 风险可管理时，才可用定性试探仓购买确认信息；
- 已有持仓不因“意图不知道”自动退出。原事件未失效且风险可管理时可持有或减仓等待判别；当前动作失败、事件转化或分歧路径造成不可管理风险时降低暴露直至退出；
- 明确下一判别点、最迟验证时点和不同结果对应的动作，不把谨慎决策描述为确认价格必跌。

用户知情后仍明确坚持时，才提供纯数据/信息降级结果；不得声称事件目标已经确认。
