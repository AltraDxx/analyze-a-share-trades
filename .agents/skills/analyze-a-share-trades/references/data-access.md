# 数据访问与时点

仅在需要选择数据源、判断新鲜度、处理缺失/冲突、请求截图、核验特殊交易时段或使用语义模型时读取。数据服务于检验盘面事件的目标、阶段和当前动作，不是默认采集清单。

## 时间与事实边界

先冻结北京时间 `analysis_as_of`，剔除其后的行情、公告和修订数据。关键证据保留：

- `as_of`：数据实际描述到的时点或报告期；
- `published_at`：来源首次正式发布时间；
- `fetched_at`：本次取得数据的时间；
- `freshness`：`realtime / near_realtime / delayed / stale / unknown`；
- `source`；
- `observed_or_inferred`。

不要用 `fetched_at` 代替 `as_of`。分钟数据相对当前市场时间超过 5 分钟视为延迟，超过 30 分钟视为陈旧；日线、财务和公告按各自自然更新周期判断。盘中当日日线是未完成记录，不得当成收盘事实。

每次正式分析重新核验时效性事实。旧对话中的事件判断只作待复核线索，先检查其延续、完成、失败或转化；成本、仓位、原始理由和偏好等稳定信息可以保留。

## 数据源选择

先说明缺少的事实将检验推断链的哪一环、可能如何改变用户动作，再选择成本最低且质量足够的来源。一个合格来源通常足够，关键事实冲突或质量存疑时才交叉核验。

- **结构化行情和计算**：优先仓库脚本、Tushare MCP 或 AkShare。
- **公告、政策和财务事实**：优先交易所、监管机构、政府和上市公司原文。
- **产业事实**：原始披露、行业组织或有方法说明的可靠来源。
- **媒体和社交内容**：只作线索，关键事实回到原文。
- **用户截图**：结构化分时或盘口缺失时的时点观测，不自动等同于实时数据。

使用 [fetch_market_data.py](../scripts/fetch_market_data.py) 获取行情时保留提供方、尝试接口、兜底状态和时点元数据。AkShare 现货自动兜底链及 Tushare API 凭证由脚本处理；同一事实已经由质量合格的 MCP 或接口返回时不重复抓取。

对来源冲突先核对代码、市场、复权、单位、币种、统计区间和更新时间。无法消除时并列披露并降低判断强度，不选择更符合当前观点的一组。

## 交易时段

- **盘前**：使用上一完成交易日、已发布事件和已结束的外围数据；竞价完成前不把竞价中状态写成最终结果。
- **盘中**：精确记录截点；当日部分成交额优先与历史同一时刻比较，不把估算写成全天事实。
- **收盘后**：只在正式数据完整后使用全天 OHLC、成交和宽度；收盘后发布的公告不得写成盘中已定价。
- **非交易日**：使用上一交易日市场事实，并把未成交验证的事件写成下一交易日假设。

盘后出现成交时，先区分收盘集合竞价、盘后固定价格、大宗交易和数据商延迟更新，再核验适用品种、价格形成、申报/撮合时间、参与者范围和字段口径。不得仅凭时段归因散户、机构或主力。

截至 2026-07-28，沪深现行规则均已把盘后固定价格交易扩展至 A 股，实际分析仍须核验当时有效规则：

- [上海证券交易所交易规则（2026 年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)
- [深圳证券交易所交易规则（2026 年修订）](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)

## 延迟、缺失与截图

关键盘中行情延迟 5—30 分钟时，显示最后 `as_of`，不判断延迟窗口内是否已经突破、跌破、封板或回流，也不给虚假精确的即时价位；可以用完成日线和事件形成条件结论。

仍缺关键数据时，只请求能够检验当前事件判断的资料：

- 个股完整当日分时：名称、代码、日期、时间、价格轴、成交量和均价线；
- 前复权日 K：通常 120 日，历史画像需要时再扩至 250 日；
- 同时点板块、核心股或相关指数分时；
- 竞价序列仅在竞价行为是判别证据时请求；
- 持仓成本、仓位和原始理由仅在会改变账户动作时请求，不索要买入日期计算持有天数。

缺个股当日行情时只做日线级判断；缺板块数据时不认定板块核心或独立强势；缺公告原文时事件只作待核验线索；缺可靠交易日历时先核验，不手算法定节假日。

## 凭证、模型与上下文

- Agent 不读取、打印、复制或提交明文密钥文件。本地脚本从环境变量或用户自行维护且已排除版本控制的 `my_api_key.md` 解析凭证，只返回非敏感诊断。
- 缺凭证时报告未配置，不要求用户在聊天中粘贴密钥。
- [deepseek_semantic.py](../scripts/deepseek_semantic.py) 只用于文本去重、字段抽取、产业映射、竞争解释和反方审查；结果标记 `inferred` 并回链原文。不得生成行情、事实或最终交易动作。
- 脚本将原始大表写入文件，只把必要特征、异常、元数据和证据引用送入模型上下文。
