## 统一规则

### 定义 D1

- 若分析日为沪深交易日，无论盘前、盘中还是收盘后，都将分析日记为 D1。
- 若分析日为非交易日，将其后的最早可执行沪深交易日记为 D1。
- 所有持有区间只按 D1—Dn 相对交易日表达，不给出预计自然日期。
- 若在 D1 收盘后分析，将下一个交易日标注为“最早可执行：D2”，避免暗示可以回到 D1 成交；不得因此重编号 D1。
- 每次新的用户提问都重新建立本次报告的 D1。已有持仓只结合 D1 之前的走势、成本和原始理由判断未来，不计算或输出已持有天数；本次继续持有或卖出安排始终从当前 D1 编号。

### 先限定策略集合，再为每只股票锁定主策略

按以下顺序行动：

1. 识别市场状态、资金与情绪、主线阶段及风险门槛，限定当前可使用的策略集合。
2. 从市场—主线—产业—公司角色链生成待深析候选。
3. 对每只候选建立贯穿大盘—板块—个股的一个主假设和一个竞争假设，判断三层是顺势共振、借势、被动拖累、逆势还是暂时脱钩。
4. 只补充能够区分该候选两个假设的证据，再分别选择一个主策略；同一批股票可以采用不同策略。
5. 为每只股票写明入场、持有、加减仓和退出条件。
6. 条件未触发时等待，不把“值得关注”写成“立即买入”。

不得先为整个市场选定唯一策略，再只寻找符合该剧本的股票；也不得为同一只股票拼接多个策略的宽松条件。

### 禁止风格漂移

- 每笔交易在入场前绑定一个策略剧本，持有期间沿用该剧本的验证和退出规则。
- 不得把失败的突破交易改称左侧潜伏，不得把短线事件交易改成长线价值持有，不得因浮亏临时放宽失效条件。
- 原策略失效后先按计划退出。若随后出现另一套策略的完整新信号，将其视为新交易，重新计算 D1、成本、风险与持有期。
- 复盘时分别评价“策略是否正确”和“执行是否正确”，不以最终盈亏倒推当时决策。

### 共同硬门槛

任一条件成立时，不发出新买入建议：

- 市场、行业、个股关键数据的时点无法核验，且缺失信息可能改变结论。
- 个股不在允许股票池内，或为 ST、停牌、流动性明显不足、实际难以成交。
- 当前价格位置、潜在收益空间和需要承担的风险明显不相称。
- 主要逻辑只来自未经证实的传闻、单一“资金流”口径或不可证伪的主力故事。
- 大盘、板块或个股的主假设与竞争假设无法可靠区分，意图状态为“不知道”。
- 个股所在主题处于明确退潮，而该策略又依赖板块共振。
- 买点已经严重偏离触发位，追入后无法设置合理失效条件。

## 策略路由

| 当前状态 | 优先剧本 | 不应选择 |
|---|---|---|
| 新催化首次出现，影响可验证，板块快速响应 | 事件驱动 | 仅因低价做趋势回调 |
| 主线核心强势，赚钱效应良好，强者持续获得溢价 | 强势延续 | 无确认的恐慌修复 |
| 主题从核心向产业链扩散，板块宽度与成交同步扩大 | 突破与板块扩散 | 孤立个股的无量突破 |
| 已确认主线完成分歧，资金重新回到核心或形成二次上攻 | 主线回流或二波 | 退潮中的机械抄底 |
| 中期趋势完整，缩量回撤到可验证支撑 | 趋势回调 | 下跌趋势中的“越跌越买” |
| 非基本面冲击造成集中抛售，随后出现修复证据 | 恐慌修复 | 有实质利空时猜底 |
| 证据冲突、当前位置不值得承担风险、主线不清或风险门槛触发 | 不交易 | 强行从候选中选一只 |

若同一只股票有多个剧本看似适用，选择与当前市场、主线、事件、价格位置和执行条件最一致的一种；不能把多个剧本的宽松条件拼成一笔交易。数据完整度决定能否正式判断，不作为不同股票之间的固定排序因子。

## 事件驱动

事件首先是所有交易分析都可以使用的证据维度。只有当新增事件是这笔交易最主要的预期差来源时，才把该股票的主策略定义为“事件驱动”；不能因为用户提供了公告就跳过市场、板块、龙头、量价和人性博弈。

### 适用环境

- 公告、政策、订单、产品价格、业绩预告或产业事件形成新的可验证预期差。
- 事件对收入、利润、供需或估值的传导路径明确，且个股是直接受益者而非弱概念映射。
- 市场风险未全面失控，相关板块至少出现成交和相对强度响应。

### 入场

- 核验原始消息、发生时间和信息层级，区分事实、解读与传闻。
- 估算市场是否已经提前交易该事件；连续大涨后才出现的公开消息通常不再是新催化。
- 优先等待第一轮剧烈波动后形成可执行价格：开盘承接、回踩不破事件锚点，或放量突破后站稳。
- 遇到涨停先假设能够成交并判断 D1 是否值得买。值得时可按计划仓位尝试，不承诺成交；不值得追入、分析时已经收盘或实际未成交时，直接给 D2 开始的条件预案。

### 确认

- 相关产业链多只个股响应，而非单股孤立异动。
- 核心受益股强于弱映射股，成交额和板块宽度同步改善。
- 当日收盘未完全回吐事件带来的超额收益。
- 后续公告、订单、价格或权威来源继续验证传导逻辑。

### 持有区间

- 基础窗口：D1 至 D5，通常 2～5 个交易日。
- D2 必须复核事件溢价和板块扩散；D3～D5 重点判断是否转化为持续主线。
- 若完整满足另一长期剧本，先结束事件交易，再按新交易重新评估，不直接延长原持有期。

### 加减仓

- 仅在事件真实性、板块共振和个股相对强度均得到新增证据后加仓。
- 高开低走、核心股落后、板块响应缩窄时减仓。
- 接近预估兑现位、事件关注度极度一致而成交放大但价格滞涨时分批兑现。

### 失效与退出

- 事件被澄清、影响明显低于预期或受益关系被证伪。
- 个股跌回事件发生前的关键价格区且无法快速收复。
- 板块没有形成共振，或核心受益股持续弱于弱映射股。
- 到达 D5 仍未产生预期走势，退出或重新评估，不以“再等等”延长期限。

## 强势延续

### 适用环境

- 市场处于风险偏好扩张或明确主线阶段，强势股次日溢价稳定。
- 个股是板块核心、中军或公认高辨识度标的，不是尾部跟风。
- 上涨由持续成交和板块协同支持，而非单次脉冲。

### 入场

- 等待分歧后的承接、关键价位回收或高位整理后的再次转强。
- 追随“强中更强”必须同时看到板块强度，不能只看个股瞬时拉升。
- 若开盘涨幅过度透支、量价失衡或买入后失效距离过大，放弃而非追价。

### 确认

- 个股持续强于指数、板块和同梯队候选。
- 分歧时有承接，回流时率先修复。
- 领涨梯队完整，板块没有只剩单一高位股维持表象。
- 次日或下一关键时段仍能获得正向反馈。

### 持有区间

- 基础窗口：D1 至 D5，通常 2～5 个交易日。
- 每日收盘复核板块溢价和核心地位，不因预计持有期尚未结束而忽略退潮信号。

### 加减仓

- 分歧后重新转强、板块同步回流且失效位上移时才加仓。
- 加速上涨后不再扩大风险；冲高放量滞涨、梯队断裂时减仓。
- 个股从核心退化为跟风，即使仍上涨，也应降低仓位。

### 失效与退出

- 跌破最近一次有效承接区或转强锚点，并在合理观察窗口内未收复。
- 板块核心集体转弱、炸板率上升或次日溢价显著恶化。
- 个股相对板块由领先转为连续落后。
- 高位反复放量冲高失败，且反弹越来越弱。

## 突破与板块扩散

### 适用环境

- 主线或新主题从少数核心向多个细分环节扩散。
- 板块成交额占比、上涨宽度、创新高数量和产业链响应同步增加。
- 个股突破日线平台、前高或整理区，且位于真实受益环节。

### 入场

- 优先选择首次有效突破或突破后的第一次可控回踩。
- 要求突破伴随适度放量，并确认不是尾盘孤立拉升。
- 比较产业核心、盘面龙头、趋势核心/中军、阶段性新核心和补涨股；综合判断地位、流动性、当前价格和所承担风险，不使用固定综合分。

### 确认

- 收盘站在突破区之上，后续回踩不快速跌回平台。
- 板块内上涨家数和成交同步扩散，而非资金只从旧核心切到一个新个股。
- 核心股保持稳定，中低位品种出现有序补涨。
- 产业催化或业绩预期能够解释扩散，而非仅靠相似名称。

### 持有区间

- 基础窗口：D1 至 D10，通常 5～10 个交易日。
- D2～D3 验证突破有效性；D5 左右复核扩散是否仍在；D10 前评估是否进入二波或趋势阶段。

### 加减仓

- 突破后缩量回踩并重新转强，或板块宽度继续扩大时加仓。
- 个股继续上涨但板块宽度收缩、成交集中于尾部跟风时减仓。
- 接近上方重大筹码压力且量价开始钝化时分批兑现。

### 失效与退出

- 放量跌回突破平台，且下一交易日无法修复。
- 板块扩散失败，只剩个别股票孤立强势。
- 公司被证明是弱映射，资金转向更直接受益环节。
- 大盘风险状态切换，突破类策略的整体成功率明显下降。

## 主线回流或二波

### 适用环境

- 方向曾是已确认主线，经历分歧或整理后，产业逻辑和市场记忆仍在。
- 调整期间板块核心未发生不可逆破坏，资金开始从其他方向回流。
- 二次催化、业绩验证或筹码整理为再启动提供新条件。

### 入场

- 不在第一次反抽时直接假定“二波”，等待核心个股重新获得相对强度、板块成交回升和关键位收复。
- 优先选择原主线核心或调整中地位上升的公司，避免纯粹因为跌幅大选择旧跟风。
- 以整理平台、前期关键成交区或回流日低点设置失效条件。

### 确认

- 核心、中军和至少一个细分环节共同回流。
- 反弹由成交和市场宽度支持，并能持续超过单个时段。
- 前期套牢区出现有效换手，而不是一触即落。
- 新一轮逻辑有增量证据，不完全依赖旧叙事复读。

### 持有区间

- 基础窗口：D1 至 D15，通常 5～15 个交易日。
- D3 验证回流持续性；D5～D8 判断是否形成二次趋势；最晚 D15 重新定性。

### 加减仓

- 确认突破整理平台、回踩不破且板块回流继续时加仓。
- 进入前高密集成交区、板块出现严重分化时减仓。
- 新核心取代旧核心时，降低旧核心仓位，不以历史地位替代当前证据。

### 失效与退出

- 回流仅持续一个时段或一个交易日，随后成交和宽度快速消失。
- 原核心持续弱于板块，或无法收复关键整理区。
- 板块重新进入退潮，低点不断下移。
- 反抽至套牢区后放量滞涨，出现疑似派发且次日确认。

## 趋势回调

### 适用环境

- 周线或日线趋势保持上行，产业景气、业绩预期或主线地位未被破坏。
- 回调更像获利回吐或市场波动，而不是基本面利空和趋势反转。
- 个股仍保持行业相对强度，回撤靠近可验证支撑。

### 入场

- 等待缩量回调至上升趋势线、重要均线、突破平台或前期成交密集区。
- 出现止跌、承接或重新站回关键位后介入，避免在连续下跌中机械猜底。
- 将“价格便宜”与“趋势仍在”分开验证；只有后者成立才使用本剧本。

### 确认

- 回调时成交收缩，修复时成交恢复。
- 板块或产业趋势未出现同步破坏。
- 个股相对强度保持，低点不持续下移。
- 基本面、订单、价格或预期没有发生负向重估。

### 持有区间

- 基础窗口：D1 至 D22，通常 7～22 个交易日，不超过约一个交易月。
- D3～D5 验证止跌，D10 复核趋势恢复，D15～D22 逐步评估兑现或退出。

### 加减仓

- 首次只使用试探仓；重新站稳关键位且板块同步恢复后加仓。
- 接近趋势上轨、前高或估值与情绪明显拥挤时减仓。
- 回调幅度扩大但没有新增确认时不得摊低成本。

### 失效与退出

- 放量跌破趋势支撑或突破平台，且不能快速修复。
- 产业或业绩逻辑发生实质性逆转。
- 板块持续弱于市场，个股又持续弱于板块。
- 到达预计持有窗口仍未恢复趋势，退出并释放机会成本。

## 恐慌修复

### 适用环境

- 指数、板块或个股因情绪、流动性或非核心事件出现集中抛售。
- 核心基本面和产业逻辑尚未被证伪。
- 抛压释放后出现止跌、流动性恢复和相对强度改善。

### 入场

- 不接第一段自由落体，等待跌速放缓、低点不再连续下移或关键位快速收复。
- 核验利空是否只影响情绪；若影响盈利、监管资格或持续经营，不使用本剧本。
- 先用小仓位试错，以恐慌低点或修复结构的关键位作为明确失效点。

### 确认

- 极端抛售后成交结构改善，卖压递减，修复有板块或指数共振。
- 个股率先收复均价、关键支撑或前一日重要价格区。
- 次日没有再次出现同级别恐慌，且修复并非单纯尾盘拉升。

### 持有区间

- 基础窗口：D1 至 D10，通常 2～10 个交易日。
- D2 必须确认修复是否持续；D3～D5 评估反弹目标；不把修复交易自动改为趋势持有。

### 加减仓

- 只有在低点确认、关键位收复和板块同步修复后加仓。
- 首次反弹进入前期套牢区时主动减仓。
- 修复量能递减、反弹高点下移或板块不跟随时快速降低风险。

### 失效与退出

- 再次跌破恐慌低点，或出现新的实质性利空。
- 修复只有个股尾盘脉冲，次日随即回吐。
- 市场进入系统性风险阶段，流动性继续收缩。
- 反弹到目标压力区后不能放量通过。

## 空仓或不交易

### 适用环境

- 市场无明确主线、快速轮动且追涨次日反馈差。
- 候选股证据冲突，或产业逻辑好但价格和交易结构没有买点。
- 数据不足、时点错位、分时图或板块参照缺失，无法判断关键条件。
- 市场处于系统性风险、连续缩量或流动性恶化阶段。
- 所有可选标的都不符合股票池、流动性要求，或当前价格与所承担风险不相称。
- 大盘—板块—个股意图链无法建立，或一个主假设与一个竞争假设同样解释核心证据。

### 入场

无。未持仓明确输出“意图不知道，建议保持空仓”，并列出重新评估所需的可观察条件。已有持仓且用户要求动作时，默认建议按 T+1、停牌、涨跌停和实际可用仓位等规则退出至空仓；这项规则表示无法可靠管理风险，不是预测价格必跌。

用户在获知上述边界后仍明确要求继续时，可以进入纯数据/事件降级分析。置顶说明不含可靠主导资金意图判断，只给可验证事实、条件触发和失效；风险基准仍为空仓，不得因用户坚持而把数据结构包装成吸筹、洗盘或派发。

### 确认

满足以下任一变化后，再重新运行策略路由：

- 市场风险状态改善。
- 主线成交、宽度和持续性得到确认。
- 候选股回到可执行价格并形成明确失效点。
- 缺失数据补齐。

### 持有区间

现金观察，无预设结束日；每个交易日可重新评估，但不得因“必须给股票”而降低门槛。同一交易日后续个股先复用大盘意图快照，只在触发快照失效条件时增量更新。

### 加减仓

无新仓。已有持仓按照其原策略剧本管理，不因暂时无新机会而被动延长。

### 失效与退出

“空仓/不交易”状态在出现完整且可执行、并能区分主假设与竞争假设的新策略信号时结束。

## 持仓期间复核

每次复核都回答以下问题：

1. 原策略是什么，在本次 D1 是否仍成立、增强或削弱？
2. 原始入场逻辑仍成立、增强还是削弱？
3. 市场、主线、产业环节和个股角色发生了什么变化？
4. 当日量价与分时支持哪个竞争性假设？
5. 是否触发加仓、减仓、退出或时间止损？
6. 下一复核点 Dn 和下一条明确失效条件是什么？

建议结论必须写出股票代码与名称，并使用以下动作之一：买入候选、等待触发、继续持有、持有但不加仓、减仓、退出、不交易。持有窗口是基础情景，不得凌驾于失效条件之上。
