# 股票池、仓位、风险与执行

本文件规定硬股票池、组合风险、仓位原则、A 股制度和涨跌停执行顺序。风险检查不能用综合分抵消，但最终只向用户展示会改变当前动作的风险。

## 一、固定股票池

默认可推荐股票池仅包含：

- 上海证券交易所主板普通人民币 A 股；
- 深圳证券交易所主板普通人民币 A 股。

排除：

1. 创业板、科创板、北交所；
2. 名称含 `ST`、`*ST` 或处于其他退市风险警示/整理状态的股票；
3. 当前停牌；
4. 明显低流动性的股票；
5. B 股、基金、债券、可转债、存托凭证等非普通 A 股证券。

不可推荐的创业板、科创板或其他股票可以作为产业、主线和情绪锚，不能进入买入结论。

### 流动性硬门槛

对最近 20 个已完成交易日计算日成交额中位数：

- 中位数低于人民币 1 亿元：不进入全市场买入候选池；
- 有效交易记录不足 15 日：视为数据不足，不进入正式买入候选；
- 数据存在冲突或无法核验：只作待补证线索。

流动性只作资格门槛，不作为候选之间的固定排名维度。用户已经持有不符合门槛的股票时仍要帮助分析，不因流动性不足拒绝卖出诊断。

## 二、组合回撤

组合回撤定义：

`drawdown = (当前组合净值 - 历史净值高点) / 历史净值高点`

规则：

- 30% 是用户设定的组合灾难性硬上限，不是目标回撤、常态容忍度或单股止损线。
- 风险应在接近灾难上限前主动降低，不能等达到 30% 才处理。
- 已实现与未实现盈亏都计入组合净值。
- 无法获得完整账户净值时，明确只能做单票和已知持仓的风险判断。
- 不自行发明 10%、15%、20% 等分层阈值；用户提供更细的风险预算时按其规则执行。

接近灾难上限时停止增加股票风险，优先按事实严重性、持仓相关性和实际执行结果压降敞口。

## 三、单笔与仓位

先确定交易逻辑、入场区域和退出条件，再决定仓位。不要先选仓位再寻找止损理由。

可以使用以下计算帮助用户理解风险，不把公式结果伪装成保证损失：

`计划价格风险 = |计划入场价 - 退出执行参考价| / 计划入场价 + 跳空与滑点考虑`

仓位依据：

- 用户明确的单笔风险预算、组合净值和已有持仓；
- 股票波动、事件风险、T+1、跳空和相关主题暴露；
- 当前策略是试探、确认后加仓还是已有持仓管理。

用户没有提供风险预算时：

- 使用“试探仓、分批、确认后再增加”等定性表达；
- 不自行指定未经用户确认的精确仓位；
- 精确仓位确实影响决策时再请求用户的风险预算，不必询问具体资产金额。

禁止：

- 因浮亏无条件摊低成本；
- 用新交易体系为已失效的旧仓位续命；
- 把 30% 组合灾难上限当作满仓依据；
- 因模型信心高而取消退出条件；
- 建议借款或杠杆放大本 skill 的股票建议。

### 意图不知道时的风险动作

当大盘—板块—个股主假设与唯一竞争假设无法可靠区分时：

- 未持仓：保持空仓，不因数据很多就强行开仓。
- 已有持仓：用户要求明确动作时，默认建议退出至空仓；按 T+1、停牌、涨跌停、实际可卖数量和仍开放的适用交易时段执行。
- 明确说明这是用户选择的风险偏好规则，原因是无法可靠管理后续路径，不是确认价格必跌，也不是把数据缺失解释为利空。
- 用户知情后仍明确要求继续分析时，可以提供纯数据/事件降级结果；风险基准仍为空仓。只有用户进一步明确要求数据驱动条件策略时，才给触发与失效条件，且不得声称主导资金意图已确认。

## 四、主题、行业与相关性

多只股票依赖同一主线、产业链、客户、商品、海外变量或政策时，应视为相关风险，不因证券代码不同就称为充分分散。

每次推荐新股票前检查：

1. 与现有持仓是否属于同一主题或产业集群；
2. 是否依赖同一客户、商品价格、政策或海外资产；
3. 同一风险事件是否会让多个持仓同时失效；
4. 新股票是否只是重复已有暴露。

用户未提供完整持仓时，只说明未完成组合相关性检查。不要自行发明精确主题上限；用户有组合约束时按其规则执行。

## 五、A 股交易制度

### 1. T+1

- 普通 A 股当日买入后不能在当日卖出。
- D1 买入后即使逻辑当日转弱，也只能给 D2 开始的优先处理方案并披露隔夜风险。
- 用户当日已有底仓时，可卖数量以账户实际可用数量为准；Agent 不猜测账户状态。

### 2. 停牌和其他硬限制

停牌、明确无交易资格或普通 A 股 T+1 等已经确认的制度/账户事实属于硬性执行限制，直接说明不能执行及后续重新分析时点。

不要把普通股票“可能有人接盘或没人接盘”做成固定输出或候选排名维度。没有明确限制时，分析交易策略；实际成交由用户订单结果决定。

### 3. 成交价格

没有实时盘口时只给价格区域、条件或关键位，不给精确队列和保证成交价。退出参考价是策略触发，不是实际成交保证。

### 4. 盘后固定价格和特殊时段

先核验交易所现行规则、适用品种、交易方式、允许参与者和数据口径。不能把盘后成交默认视为散户专属，也不能因机构可参与就认定成交来自主力。详细解释按照 [data-and-models.md](data-and-models.md) 和 [intraday-game.md](intraday-game.md)。

## 六、涨跌停：先决策，后尝试

涨跌停是价格、情绪、拥挤、事件定价和隔夜风险证据，不是“必然无法成交”的同义词。

### 1. 统一顺序

```text
假设能够成交，先判断 D1 应不应该交易
├─ D1 应交易
│  ├─ 给尝试交易的数量/条件策略，不承诺成交
│  ├─ 成交后：按实际成交进入持有或退出策略
│  └─ 未成交/部分成交：按真实仓位进入 D2 条件预案
└─ D1 不应交易，或已无用户可使用的适用交易时段
   └─ 直接给 D2 开始的条件预案
```

不建立涨跌停可交易性三态，也不把一字板直接判成不可交易。常规连续竞价收盘后，先按本文件的特殊时段规则检查盘后固定价格等机制，不能仅凭“已收盘”跳到 D2。

### 2. 涨停买入

- 先判断事件、主线、龙头地位、价格位置、拥挤和 T+1 风险是否支持 D1 买入。
- 支持时允许用户按计划仓位尝试，不因“一字涨停”标签直接否决。
- 不支持追入时，不讨论能否排到，直接给 D2 的开板、承接、板块和取消条件。
- D1 尝试未成交时，D2 重新结合竞价、板块、开板成交和风险判断，不自动追涨。

### 3. 跌停卖出

- 先判断原逻辑、事件、主线和风险是否要求 D1 卖出。
- 应卖时允许用户尝试；不承诺成交，也不把理论退出价写成成交价。
- 未成交时给 D2 首次出现真实执行机会时的条件处理，但仍检查是否出现足以改变原判断的新事实。
- 部分成交时以剩余真实仓位制定 D2 方案。

买入跌停或卖出涨停同样先由完整交易分析决定，不能仅因价格达到限制就自动产生动作。

## 七、买入与卖出检查

### 买入前

至少确认：

- 股票池和流动性硬门槛合格；
- 当前市场允许所选策略；
- 主线、公司独立事件或其他交易逻辑可验证；
- 龙头/产业/盘面角色清楚；
- 日线和分时没有与动作直接冲突的硬事实；
- 入场、持有和卖出策略可执行；
- 组合回撤和相关暴露没有触发用户限制；
- T+1、公告和跳空风险已被纳入。

风险不合格时输出等待或不买，不用分数相抵。

### 卖出判断

按严重性检查：

1. 财务真实性、监管、退市或持续经营等不可逆风险；
2. 原始交易逻辑或事件被证伪；
3. 主线退潮、龙头地位丧失或公司角色恶化；
4. 日线、成交和分时结构破坏；
5. 高位主导资金与人性博弈出现派发/兑现迹象；
6. 达到策略目标、窗口或有更合适的组合安排。

试盘、洗盘、诱多、诱空和派发只作内部竞争性解释，不以单根 K 线或一段分时作为唯一卖出理由。

## 八、输出检查

- [ ] 股票池硬过滤已通过，或明确是已有持仓诊断；
- [ ] 30% 只被描述为组合灾难上限；
- [ ] 未使用未经用户确认的精确仓位和主题比例；
- [ ] 相关性已按可得持仓检查；
- [ ] T+1 和停牌等硬限制已与涨跌停区分；
- [ ] 涨跌停先完成假设可成交时的 D1 动作判断；
- [ ] D1 应交易时给尝试方案，未执行时给 D2 条件预案；
- [ ] 未把提交委托当作实际成交；
- [ ] 未把普通的难买难卖做成候选排序维度或冗长固定输出；
- [ ] 意图不知道时已按未持仓空仓、已有持仓退出至空仓处理，并区分了风险偏好与价格预测；
- [ ] 只向用户展示会改变当前动作的风险。
